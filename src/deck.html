Before Case 4 · what is Intel Loihi 2?

A chip built like a brain

CPU

a few big cores · memory far away

Loihi 2

neuromorphic · 128 tiny cores, memory inside
Memory
Separate RAM: data travels back and forth
Inside each core, next to its neurons
Timing
Global clock: update every neuron every step
Event-driven: works only when a spike arrives
Talks by
Reading and writing shared memory
Spike messages over an on-chip mesh
Scale
General purpose, any program
Up to ~1 M neurons per chip, spiking models only

Source: Intel Labs, Loihi 2 technology brief, 2021 · animated sketches, not to scale

Takeaways

What the fly teaches us

Complete wiring for both sexes: 166 k+ neurons

Open code runs it on GPUs, browsers, chips

Wiring alone ≠ a working mind, yet

Sparse, recurrent, pre-wired = huge energy savings

Open questions

Can a wiring diagram guide how we design AI models? What do learning and neuromodulators add on top of wiring? Can neuromorphic chips close the energy gap?
