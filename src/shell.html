Under the hood

A tiny spiking engine with fly learning rules

Neuron model

Every hidden neuron is leaky integrate-and-fire, stepped every 1 ms. Sensory neurons fire as Poisson spike trains whose rate is set by the game.

v ← v − v·Δt/τ + Σ w·spikes  ·  if v ≥ 1: spike, v ← 0
step(){ // dt = 1 ms, tau = 20 ms
  for each neuron i:
    if input:  spike = rand() < rate·dt
    else:      v += −v·0.05 + noise
               if v ≥ th: spike, v = 0
  for each spike: v[post] += w
  trace[i] = trace[i]·0.996 + spike  // ~250 ms memory
}

Learning rules

  1. Crash-gated credit (runner, parking): after a failure, change only the synapses whose input neurons were recently active, signed by whether the action came too early or too late.
  2. Dopamine-gated plasticity (kebab): reward or punishment strengthens or weakens Kenyon-cell → MBON synapses that were active at the cut, like the fly mushroom body.
  3. Error-driven credit (slicer): misses strengthen the saber that should have moved; wrong swings weaken the one that did.

Wiring stays fixed; only one layer of synapses learns. That mirrors connectome-constrained models such as flyvis.

Learning rules at a glance

All three share one idea: a synapse remembers how recently its input fired (an eligibility trace). When a teaching signal arrives, only recently active synapses change.

The ideas behind the rules

A three-factor rule changes a synapse only when (1) its input fired, (2) its output fired, and (3) a broadcast teaching signal arrives. The signal often comes late, so each synapse keeps a fading memory of its activity: an eligibility trace. The arcade uses the simplest form, input trace × teaching signal.

  1. 1949Hebb: cells that fire together wire together (factors ① + ②)
  2. 1958–60Perceptron, delta rule: change weights by input × error
  3. 1972Rescorla–Wagner: learning is driven by surprise, not reward itself
  4. 1997Schultz, Dayan & Montague: dopamine neurons signal reward-prediction error (factor ③)
  5. 2007–16Izhikevich; Frémaux & Gerstner: eligibility traces link a delayed reward to the right synapse
  6. 2015–16Hige et al.; Aso & Rubin: in the fly mushroom body, dopamine rewrites Kenyon-cell → MBON synapses
Crash-gated creditThree-factor rule + eligibility trace. The crash is factor ③, signed by “too early” or “too late”. Solves which synapse caused it? across a delay.
Dopamine-gatedThe fly mushroom body: sparse Kenyon cells carry the trace, PAM/PPL1 dopamine is factor ③. Simplified: in real flies dopamine mostly weakens KC→MBON synapses in its own compartment.
Error-driven creditThe delta rule: Δw ∝ input × (target − output). A teacher says which saber should have moved, like supervised learning.

Why not backpropagation? Backprop needs every synapse to receive an exact error sent backward through all layers. These rules are local: each synapse uses only its own trace plus one broadcast signal, something a brain or a neuromorphic chip can do.

Roadmap

  1. Swap hand-wired circuits for real MaleCNS v1.0 subsets from neuPrint (for example LC10a → AOTU → DN, as in the dino repo).
  2. Add a shuffled-wiring control to every game to test whether the real wiring matters.
  3. Run the full brain in a Web Worker with WebAssembly, as Lulzx’s project does.
  4. Log runs and export learning curves for the paper.
